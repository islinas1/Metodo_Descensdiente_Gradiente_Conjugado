01 — Fundamentos
¿Qué es el Descenso del Gradiente Conjugado?

El Problema

El Método de Descenso del Gradiente Conjugado (DGC) es el método iterativo más prominente para resolver sistemas lineales de gran escala de la forma:

Ax = b

Donde A es una matriz simétrica definida positiva, x es el vector incógnita, y b es el vector conocido. Resolver este sistema es equivalente a minimizar la función cuadrática convexa:

φ(x) = ½ xᵀAx − bᵀx

El mínimo de φ(x) ocurre exactamente en la solución x* = A⁻¹b.

¿Por qué "Conjugado"?

El núcleo del método es generar direcciones de búsqueda p₀, p₁, ..., p_{n-1} que sean conjugadas respecto a la matriz A:

pᵢᵀ A pⱼ = 0    (para todo i ≠ j)

Esta propiedad garantiza que cada paso de optimización no "arruine" el progreso logrado en pasos anteriores. A diferencia del gradiente estándar que puede zigzaguear, las direcciones conjugadas convergen en máximo n iteraciones (en aritmética exacta).

El método de Descenso del Gradiente Conjugado es un caso particular de método de descenso. Los métodos de descenso están especialmente indicados para la resolución de sistemas huecos (cuya matriz tiene muchos ceros).

Esto combina lo mejor de dos mundos: la simplicidad del descenso del gradiente con la convergencia finita de los métodos directos.

Las 5 Operaciones Clave

01
Calcular el tamaño de paso: αₖ = (rₖᵀrₖ) / (pₖᵀApₖ)
02
Actualizar la posición: x_{k+1} = xₖ + αₖ pₖ
03
Actualizar el residuo: r_{k+1} = rₖ + αₖ Apₖ
04
Calcular coeficiente conjugado: βₖ₊₁ = (r_{k+1}ᵀr_{k+1}) / (rₖᵀrₖ)
05
Nueva dirección de búsqueda: p_{k+1} = -r_{k+1} + βₖ₊₁ pₖ

Convergencia

La velocidad de convergencia depende del número de condición κ(A) = λ_max / λ_min:

‖xₖ − x*‖_A ≤ 2 · ((√κ − 1)/(√κ + 1))ᵏ · ‖x₀ − x*‖_A

Si A tiene solo r valores propios distintos, el método converge en exactamente r iteraciones. Si los valores propios se agrupan en pocos clusters, la convergencia práctica es mucho más rápida que lo teórico.

El precondicionamiento (transformar el sistema con P ≈ A⁻¹) reduce κ y acelera la convergencia dramáticamente.

¿Cuándo usar el Descenso del Gradiente Conjugado?

✓
Matrices grandes y dispersas — Diferencias finitas, elementos finitos, redes de distribución. El DGC solo necesita multiplicar A×v, no almacenar toda la matriz.
✓
Memoria limitada — Solo almacena unos pocos vectores de tamaño n, vs. O(n²) de métodos directos.
✗
Matrices densas pequeñas — Para sistemas pequeños, la factorización directa (Cholesky/LU) es más eficiente.
✗
Matrices no simétricas — Se necesitan variantes como GMRES o BiCGSTAB.
02 — Aplicaciones
¿Dónde se utiliza?
🏗️

Análisis Estructural

Cálculo de esfuerzos y deformaciones en edificios y puentes. Los sistemas de elementos finitos generan matrices dispersas enormes, ideales para DGC.

🌊

Dinámica de Fluidos

Simulación de flujo de agua, aire o petróleo. Las ecuaciones de Navier-Stokes discretizadas producen sistemas lineales resueltos con DGC precondicionado.

⚡

Circuitos Eléctricos

Análisis de redes eléctricas con miles de nodos. La matriz de admitancias es simétrica y dispersa — caso perfecto para el método.

🧠

Machine Learning

Optimización de funciones de pérdida en redes neuronales. Las variantes no lineales (Fletcher-Reeves, Polak-Ribière) se aplican en entrenamiento.

🗺️

Redes de Distribución

Cálculo de presiones en redes de agua o gas. El equilibrio de flujos genera sistemas Ax=b simétricos resueltos eficientemente con DGC.

🔬

Ecuaciones Diferenciales

Resolución numérica de EDPs con diferencias finitas o elementos finitos. El DGC es el solver estándar para las matrices resultantes.

04 — Implementación
Código Python

Implementación completa del método con el ejemplo del documento: sistema 3×3.

gradiente_conjugado.py 
import numpy as np

def gradiente_conjugado(A, b, x0=None, tol=1e-10, max_iter=1000):
    """
    Método de Descenso del Gradiente Conjugado para Ax = b
    
    Parámetros:
        A       : Matriz simétrica definida positiva (n x n)
        b       : Vector del lado derecho (n,)
        x0      : Punto inicial (default: vector cero)
        tol     : Tolerancia para el criterio de paro
        max_iter: Número máximo de iteraciones
    
    Retorna:
        x       : Vector solución
        historial: Lista de puntos visitados (para visualización)
    """
    n = len(b)
    
    # Punto inicial
    if x0 is None:
        x = np.zeros(n)
    else:
        x = x0.copy()
    
    # Residuo inicial: r = b - Ax
    r = b - A @ x
    # Primera dirección de búsqueda
    p = r.copy()
    
    rs_old = r @ r  # rᵀr
    historial = [x.copy()]
    
    for k in range(max_iter):
        Ap = A @ p  # Producto matriz-vector
        
        # Paso 1: Tamaño de paso óptimo
        alpha = rs_old / (p @ Ap)
        
        # Paso 2: Actualizar posición
        x = x + alpha * p
        historial.append(x.copy())
        
        # Paso 3: Actualizar residuo
        r = r - alpha * Ap
        
        rs_new = r @ r
        
        # Criterio de paro
        if np.sqrt(rs_new) < tol:
            print(f"Convergencia en {k+1} iteraciones")
            break
        
        # Paso 4: Coeficiente conjugado
        beta = rs_new / rs_old
        
        # Paso 5: Nueva dirección conjugada
        p = r + beta * p
        
        rs_old = rs_new
    
    return x, historial
